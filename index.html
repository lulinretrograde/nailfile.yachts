How to use ShareX with nailfile.yachts

  1. Download and install ShareX
  2. Click the "Download ShareX Config" link to download the .sxcu file
  3. Double-click the downloaded .sxcu file to import it into ShareX
  4. In ShareX, go to: Destinations → Custom uploader settings
  5. Select "nailfile.yachts" from the list
  6. Go to: Destinations → Image uploader → Custom uploader → nailfile.yachts
  7. Done! Now when you capture screenshots, they'll upload automatically

Tip: You can also set it for file uploads and text uploads in the Destinations menu.
